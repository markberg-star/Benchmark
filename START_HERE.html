A personal workout log for your iPhone. Publish the app, add it to your Home Screen, then import your routines privately.

Publish this

The contents of app/, including every file and its assets and icons folders.

Keep this private

private/Benchmark_Private_Routines.json, your exported backups, and your original workout screenshots.

Upload only the app folder's contents. Do not upload this whole package or ZIP to your public GitHub repository.

1. Put the app on GitHub

  1. On your computer, unzip the download. Open GitHub and create a new Public repository named benchmark. Add a README when creating it.
  2. Choose Add file → Upload files. Drag in everything inside the package's app folder. Keep its folders intact. index.html should appear at the repository's top level, not inside another app folder.
  3. Commit the files to main.
  4. Open Settings → Pages. Choose Deploy from a branch, then main and /(root). Save.
  5. Wait for publication, then use Visit site on that page. Copy the link GitHub provides and send it to your phone.

Your address normally looks like https://YOUR-USERNAME.github.io/benchmark/. Use GitHub's actual link.

2. Add it to your iPhone

  1. Open the live link in a normal Safari tab.
  2. Open Share → Add to Home Screen. Turn on Open as Web App if offered, keep the name Benchmark, and tap Add.
  3. Open the new Benchmark icon while online. Use this Home Screen version consistently for your records.

Install first, then import. Do not assume a regular Safari tab and the Home Screen app will always share the same records.

3. Import your starting routines

  1. Save private/Benchmark_Private_Routines.json into Files on your iPhone. Choose On My iPhone if you want to keep the file out of iCloud Drive.
  2. Open Benchmark from its Home Screen icon and tap Import.
  3. Select the JSON, review the preview, tick the confirmation, and restore it.

You get three routines and 27 reference sets. The reference numbers are undated. Your completed workout history starts empty.

Import replaces records. It does not merge them. Once you have logged workouts, export before importing anything you might want to undo. The starter file is for initial setup, not a later update.

4. Log your workout

  1. Start a routine. The active set shows your previous result, today's target, and large fields for actual weight and reps.
  2. Enter today's numbers. Use previous weight copies only weight. Reps stay as they are, and copying never completes a set.
  3. Tap Complete set after the set. Benchmark advances to the next incomplete set. Use All exercises to move around, or tap a completed set to review it.
  4. Watch for Saved on this device. Closing and reopening lets you resume the unfinished workout.
  5. Tap Finish workout, review the completed-set count, and confirm. The saved-workout screen confirms it is in your history.

Targets start at the previous completed rep count plus one, using that exact exercise's latest completed workout across any routine. Unchecked sets do not become future comparisons.

Weights: use pounds per dumbbell, the displayed resistance for machines and cables, and reps only for bodyweight movements. Assisted machines record pounds of assistance: a higher number means more help. Use a consistent total-weight convention on Smith machines.

Changing the plan: Edit lets you add, replace, remove, or reorder exercises and sets. Choose This workout only or Update saved routine. Completed history stays intact. The library includes standard gym movements and custom names, with muscle-group pictures to help you scan.

5. Keep a backup

Export saves a JSON file containing routines, custom exercises, history, settings, and any unfinished workout. Check that the download appears in Files. If iPhone shows a preview, use Share → Save to Files.

Export regularly and before updates or imports. A backup kept only on your phone cannot protect against losing that phone, so you can also keep a private copy on your computer.

Your workout entries stay in this app's local browser storage. Benchmark has no account, analytics, or cloud database. Clearing website data, removing the installed app, device storage pressure, or losing the phone can remove records. Anyone using your unlocked phone can open them.

Before your first real workout

These checks still need to be done on your actual iPhone:

  • Confirm the icon, text, keyboard, and buttons work comfortably.
  • Enter a test set, wait for Saved on this device, close the app, and reopen it. Confirm the entries remain.
  • Try Use previous weight and confirm it leaves reps blank. Complete a test workout, then check the next workout's previous result and target.
  • Export, confirm the file exists, and restore it through the import preview.
  • After the app loads fully online, turn on Airplane Mode and confirm you can reopen it, log a set, and save. Reconnect afterward.

Use a test routine or restore your starter file after testing, before your first real session, if you want history to begin clean.

Updating later

Export a fresh backup and finish any active workout. Upload the new release's app contents to the same repository, replacing the files. Keep the same website address and Home Screen icon. After GitHub publishes, open Benchmark online, check for updates in Help, and apply the update when offered.

Do not clear website data or reinstall the starter import as part of an update. App-file updates are separate from your local workout records.

Quick fixes

The GitHub link shows 404

Check that index.html is at the repository root, Pages uses main and /(root), and the deployment in Actions succeeded. Publication can take a few minutes.

The app says changes are not saved

Keep the app open and export your entries. Follow the visible Retry saving or Reload saved data action. If another app tab has newer records, export this tab before reloading it.

My routines look missing

Check you opened the same Home Screen icon and URL used before. Restore your latest backup if needed. Do not reimport the starter over records you want to keep.

An import is rejected

Choose a Benchmark JSON export or the included private starter file. Do not choose the ZIP or a screenshot. A rejected file leaves existing records unchanged.
