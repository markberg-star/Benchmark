# Your starting routines

Keep this file and `Benchmark_Private_Routines.json` private. Do not upload them to GitHub. Upload only the contents of the public app folder, then import the private JSON from inside the Home Screen app on your iPhone.

This starter has **three routines, 15 exercises, and 27 reference sets**.

The numbers below were transcribed from your supplied routine screenshots. They are saved as **undated reference results**, not as completed workouts with an invented date. Your completed workout history starts empty. Each initial rep target is one more than the corresponding screenshot rep value. Today’s weight and actual reps start blank, and no sets start completed.

All weights are pounds. Dumbbell values are **per dumbbell**. Machine and cable values are the displayed load. Smith machine values preserve the numbers in your screenshots without adding or subtracting a bar weight. Hanging knee raises use reps without a required weight.

## Using these routines

Start a routine and enter the current set's actual weight and reps. **Use previous weight** copies only the weight; you still enter actual reps and tap **Complete set**. The next incomplete set then becomes active. Wait for **Saved on this device** before closing, and use **Resume workout** when you return. Finishing asks you to confirm the completed-set count, then opens the saved-workout screen.

You can add presets beyond these starting movements, or create custom exercises. For an assisted machine, record the positive pounds of assistance displayed by the machine: more assistance means more help. None of the starting routines above uses that assistance convention.

## After your first workout

Once you complete an exercise in Benchmark, its latest completed performance becomes the comparison for future workouts, including other routines. The original reference values remain part of your backup but do not override newer completed results. Exercise variations and equipment choices remain separate, so replacing an exercise never transfers another exercise’s weights into its history.

Import is a full restore, not a merge. Read the preview and export your current records before replacing data you want to keep. This starter import is intended for initial setup; use your own latest exported backup for recovery later.
